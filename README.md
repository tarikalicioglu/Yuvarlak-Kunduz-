# Yuvarlak Kunduz

Gökyüzündeki ince bir yolda top olup yuvarlanan sevimli bir kunduzun 3D tarayıcı oyunu.

- Parmağını sağa sola kaydır: kunduz yön değiştirir
- Ekrana dokun: zıplar
- 500 level (10 dünya × 50), boss levelleri, günün leveli, sonsuz mod
- 3 can, kontrol bayrağı, güçlendirmeler, kostüm dükkânı, koleksiyon
- Etrafta uçan balıklar, bir çocuğun çizdiği balık resminden yapıldı

İlerleme her oyuncunun kendi cihazına (localStorage) kaydedilir.

Tek dosya: `index.html` (three.js r128, cdnjs üzerinden).
